## 💡 4. Judge Q&A & Technical Talking Points

Be prepared to answer these common technical questions from hackathon judges:

| Question | Short Winning Answer |
| :--- | :--- |
| **Why not just use an on-chain limit order or Gelato bot?** | Transparent bots and on-chain limit orders broadcast their trigger prices in the public mempool. MEV searchers see pending transactions and front-run or sandwich them, forcing the borrower into an 8% liquidation penalty. Aegis-F executes inside encrypted TEE RAM with zero mempool footprint until execution. |
| **How does FTSOv2 give Aegis-F an edge?** | FTSOv2 provides sub-second (~1.8s) decentralized price updates with block-latency freshness and on-chain staleness validation, allowing the enclave to react before centralized off-chain oracles or liquidator bots can detect the price divergence. |
| **What is the difference between `MODE=0` and production?** | In this testnet submission, the Go TEE daemon runs in `MODE=0` (local hardware simulation) to avoid GCP Confidential Space hardware charges during testing while running identical EVM signing logic. Production deploys the compiled binary to AMD SEV-SNP with hardware attestation on Coston2's `TeeMachineRegistry`. |
| **How does dynamic repayment improve over standard liquidation?** | Standard Compound/Kinetic liquidations seize 50% of the loan (close factor) plus an 8% bonus. Aegis-F calculates $\Delta D = D - \frac{C \cdot P \cdot CF}{HF_{target}}$, repaying only the exact amount needed to reach a safe $1.30$ buffer, preserving borrower capital. |

## 🛠️ 5. Recording & Production Checklist

Before pressing record, make sure your environment is set up for maximum visual quality:

- [ ] **Resolution:** Set screen resolution to `1920x1080` (1080p) or `3840x2160` (4K) with browser zoom at `100%` or `90%`.
- [ ] **Hardhat Tests Verified:** Run `npx hardhat test` (13/13 passing).
- [ ] **Go TEE Keeper Running:** Run `cd fce-keeper && go run main.go` in a separate terminal.
- [ ] **Frontend Dev Server Running:** Run `cd frontend && npm run dev` at `http://localhost:3000`.
- [ ] **Sound Enabled:** Ensure browser audio is unmuted so alert beeps and rescue chimes are audible in the recording.
- [ ] **Clean Browser:** Hide bookmarks bar, disable browser extensions, and use fullscreen mode (`F11` or browser presentation mode).
- [ ] **Mouse Smoothness:** Move mouse deliberately and use click animations.
